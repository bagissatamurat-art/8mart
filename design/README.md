# Дизайн-референс (HTML-макеты)

Это не код приложения, а макеты, по которым он сверяется. Открывать через локальный сервер (из file:// не загрузятся данные):

```bash
cd design && npx serve .     # или: python3 -m http.server 8080
```

- App UI Kit.dc.html — токены и компоненты приложения (светлая/тёмная тема) + таблица «компонент → Flutter-виджет».
- UI Kit.dc.html — UI Kit сайта (общий источник токенов).
- 01…08 *.dc.html — экраны; смотреть артборды 390 (mobile). Состояния переключаются в панели Tweaks.
- data.js — мок-данные и бизнес-логика (planShipments, splitOptions) — Dart-версия в lib/domain.
- geo.js ключи вырезаны: подсказки адреса и карта в копии не работают — это ожидаемо.
