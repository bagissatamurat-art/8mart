# 8mart app — спецификация сервисных частей

## 1. Push-уведомления
Код: `lib/core/push.dart` (типы, каналы, куда ведёт тап). Отправляет бэкенд (FCM data-payload `{type, orderId?, shipment?, status?, link?}`), тексты — на языке пользователя (`Accept-Language` при регистрации устройства).
Разрешение спрашиваем **после первого заказа** на экране статуса (своя карточка → системный диалог). Не при запуске.

| # | type | Канал | Когда | Заголовок / текст (ru) | Тап → |
|---|---|---|---|---|---|
| 1 | orderAccepted | orders | оплата прошла | Заказ №8M-10482 принят · Соберём за 30–40 минут | /order/:id |
| 2 | orderAssembling | orders | начали сборку | Собираем заказ · Проверяем наличие и упаковываем | /order/:id |

| 5 | readyForPickup | orders | готов к выдаче | Заказ готов к выдаче · пр. Мангилик Ел, 55, храним 24 часа | /order/:id |

Правила:
- **Каналы** (Профиль → Настройки → Уведомления): orders и bonus включены по умолчанию; **promo и cart — только с согласия (opt-in)**, выключены по умолчанию. Android — отдельные notification channels (`androidChannels`), orders — высокий приоритет.
- Если системное разрешение выключено — в настройках плашка «Открыть настройки».
- Пока приложение открыто (foreground) — не системный баннер, а `showMartToast` + обновление `OrderCubit`.
- Смешанный заказ: один push на каждое отправление («Доставка 1 из 2 · курьер в пути»).
- Тихие часы 22:00–09:00 для promo/cart (бэкенд). Статусные — всегда.
- Бэкенд: `POST /devices {fcmToken, platform, lang}`, `PUT /me/notifications {orders, bonus, promo, cart}`.

## 2. Где что переключается
```
Профиль (вкладка)
├─ [вошёл] шапка: имя, телефон, активный заказ
├─ [вошёл] Мои заказы · Избранное · Адреса · Способы оплаты · Промокоды · Бонусы · Личные данные
├─ Настройки  (значение: «Русский · Как в системе»)          /profile/settings
│   ├─ Язык: Русский / Қазақша (шторка)                       — сразу, без перезапуска
│   ├─ Тема: Как в системе / Светлая / Тёмная (шторка)        — по умолчанию «Как в системе»
│   ├─ Уведомления → переключатели каналов                    /profile/settings/notifications
│   ├─ [вошёл] Вход по Face ID / отпечатку (switch)
├─ Документы                                                   /profile/settings/documents
├─ Поддержка: WhatsApp · телефон
└─ [вошёл] Выйти (серым)
```
- Язык при первом запуске — по языку системы (kk → қазақша, иначе русский). Хранится в `SettingsCubit` (hydrated) и уходит на бэкенд для текстов push и SMS.
- Гость видит Настройки и Документы тоже (без Face ID).
- Удаление аккаунта — Личные данные → серая ссылка внизу (требование App Store 5.1.1(v)).

## 3. Документы
Открываются во встроенном браузере (SFSafariViewController / Custom Tabs), URL — из `GET /app/config`, чтобы юристы меняли тексты без релиза.
**Тексты пока не написаны** — в приложении только пункты меню и ссылки-заглушки `https://8mart.kz/legal/<slug>`; страницы сделает бизнес позже.
| Документ | Где ещё ссылка |
|---|---|
| Публичная оферта | чекбокс в оформлении |
| Политика конфиденциальности | экран входа («Продолжая, вы соглашаетесь…»), App Store / Google Play listing |
| Согласие на обработку персональных данных (Закон РК «О персональных данных») | экран входа |
| Условия доставки и возврата | карточка товара (блок «Доставка»), статус заказа при отмене |
| Правила бонусной программы | раздел «Бонусы» |
| Лицензии открытого ПО | `showLicensePage` (Flutter) |
| О приложении | версия и сборка (`package_info_plus`) |

## 4. Что ещё не забыть
- **Разрешения** и тексты-объяснения: геолокация (Info.plist `NSLocationWhenInUseUsageDescription` — «Чтобы определить адрес доставки»), уведомления, Face ID (`NSFaceIDUsageDescription`). Камера/фото не нужны.
- **Privacy для сторов**: App Privacy (Apple) и Data safety (Google) — телефон, имя, адреса, история заказов, геолокация (по запросу), push-токен. Не собираем: контакты, фото.
- **Аналитика** (Firebase Analytics / AppMetrica): `view_item`, `add_to_cart`, `begin_checkout`, `add_payment_info`, `purchase`, `login`, `search`, `select_receive_method`, `split_choice`. Отдельного согласия на аналитику нет (решение бизнеса); сбор описан в политике конфиденциальности.
- **Crashlytics / Sentry** — с первой сборки.
- **Ошибки оплаты**: оплата не прошла / отменена в Kaspi / 3-D Secure отклонён → экран оформления с плашкой и «Повторить оплату»; заказ держим 30 минут.
- **Доступность**: масштаб текста до 200 % (проверено в Widgetbook), Semantics на кнопках-иконках, контраст 4.5:1 в обеих темах.
- **Оценка приложения** (`in_app_review`) — после 2-го доставленного заказа, не чаще раза в 90 дней.
- **Иконка и сплэш**: `flutter_launcher_icons`, `flutter_native_splash` (логотип на #F2F2F4 / #0F0E11 в тёмной).
- **Материалы для сторов**: скриншоты 6.7" и 6.5" (iOS), 1080×1920 (Android), описание ru/kk, ключевые слова.
- **Обязательное обновление**: `GET /app/config {minVersion}` → `/update`.
- **Версия API** в заголовке запросов (`X-App-Version`) — чтобы бэкенд мог отключать старые версии.
