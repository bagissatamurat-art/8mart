# Аудит mobile-макетов → приложение 8mart (Flutter, iOS + Android)

Решения: один дизайн на обе платформы, Bloc/Cubit, Mapbox, Widgetbook. Нужны: push, deep links, автоподстановка кода, биометрия, тёмная тема, казахский, офлайн-кеш каталога.

## 1. Что меняется при переходе сайт → приложение

| Сейчас в макете 390 | В приложении |
|---|---|
| Нарисованный статус-бар 44 px | `SafeArea` / `MediaQuery.padding.top`, статус-бар системный (светлые/тёмные иконки по теме) |
| Таб-бар 84 px с «запасом» под home indicator | Таб-бар 64 + `padding.bottom` устройства. 4 вкладки: Главная, Каталог, Корзина (счётчик), Профиль |
| Кнопка «назад» 40 px в шапке экрана | 44×44 (hit-area 48). + системный свайп назад на iOS, системная кнопка «назад» на Android закрывает сначала шторку/модалку, потом экран |
| Модалки/шторки (фильтры, товар, способ получения) | `showModalBottomSheet` с ручкой-граббером, свайп вниз закрывает, высота до 94 %, учитывает клавиатуру (`viewInsets`) |
| Закреплённая панель CTA (белая, линия #EEEDF1) | Та же, + `padding.bottom`; поднимается над клавиатурой только на экранах с полями |
| Ссылки между страницами | `go_router`, у каждого экрана свой путь — он же deep link |
| «Поделиться» | `share_plus` (системный шар) |
| Карта Leaflet в iframe | `mapbox_maps_flutter`; контракт «пин → адрес» тот же, геокодирование — через бэкенд (DaData) |
| Kaspi Pay — ссылка на оплату | Открыть приложение Kaspi по deep link оплаты → возврат в 8mart по universal link `8mart.kz/pay/return?order=` → статус заказа (поллинг + push) |
| Оплата картой | Страница шлюза во `WebView` (3-D Secure); сохранённые карты — токены шлюза, в приложении только маска |
| Шрифт Onest с Google Fonts | Шрифт вшит в приложение (офлайн, без мигания) |

## 2. Размеры касания (правка макетов)
Минимум 44 pt (iOS) / 48 dp (Android). Визуально элемент может быть меньше — зона нажатия расширяется.
- Чипы 36 → визуально 36, hit-area 48.
- Степпер 36 → в приложении 40, кнопки ± hit-area 44.
- Крестик удаления в строке корзины 36 → hit-area 44.
- Кнопка «назад» 40 → 44.
- Сердце избранного на карточке: зона 44.

## 3. Функции только для приложения
- **Push** (FCM + APNs): смена статуса по каждому отправлению (курьер/Газель), «Готов к выдаче», возврат денег. Тап → экран статуса. Разрешение спрашиваем **после первого заказа** на экране статуса, не при запуске.
- **Deep links / Universal & App Links**: `8mart.kz/p/{id}` товар, `8mart.kz/c/{slug}` категория, `8mart.kz/order/{id}` статус, `8mart.kz/auth/tg?token=` возврат после Telegram-бота, `8mart.kz/pay/return`. Нужны `apple-app-site-association` и `assetlinks.json` на домене.
- **Автоподстановка кода**:
  - SMS: iOS — `autofillHints: oneTimeCode`; Android — SMS Retriever API (без разрешения на SMS, нужен хэш приложения в тексте SMS).
  - WhatsApp: Android — one-tap autofill шаблона WhatsApp Business (нужен package name + hash подписи); iOS — автоподстановки нет, показываем «Вставить код» при коде в буфере.
- **Telegram-вход**: кнопка открывает `t.me/<bot>?start=<token>`; после «Поделиться номером» бэкенд шлёт push/событие, приложение возвращается и входит. Если вернулись вручную — поллинг статуса токена.
- **Face ID / отпечаток** (`local_auth`): не заменяет вход по телефону. После первого входа предлагаем «Входить по Face ID» — refresh-токен в `flutter_secure_storage` открывается биометрией. Выключается в «Личных данных».
- **Тёмная тема**: системная по умолчанию + переключатель в профиле (Системная / Светлая / Тёмная). Фото товаров на белом остаются в белой скруглённой подложке. Логотип Kaspi и кнопку Kaspi не перекрашиваем.
- **Казахский**: все строки в ARB (`app_ru.arb`, `app_kk.arb`). Склонения: ru — one/few/many, kk — one/other. Казахский в среднем на 15–25 % длиннее — кнопки и чипы без фиксированной ширины. Переключатель языка в профиле.
- **Офлайн-кеш**: категории, каталог, карточки и фото кешируются; корзина и способ получения хранятся локально (`hydrated_bloc`). Без сети — плашка «Нет интернета», оформление и оплата недоступны, цены пересчитываются с сервера перед оплатой.

## 4. Экраны, которых нет в макетах (нужны приложению)
1. Сплэш (логотип на фоне темы).
2. «Нет интернета» (плашка + пустое состояние каталога без кеша).
3. Запрос push после первого заказа (свой экран-объяснение перед системным диалогом).
4. Предложение Face ID после входа.
5. Обязательное обновление приложения.
6. Профиль → «Настройки»: язык, тема, уведомления, Face ID.

## 5. Расхождения в текущих mobile-макетах
- Статус-бар и home indicator нарисованы — в коде не повторять.
- Высоты кнопок «назад» 40 и 44 на разных экранах → единые 44.
- Степпер 36 в корзине → 40.
- Ячейки кода: состояние «вставить из буфера» не нарисовано (нужно для iOS + WhatsApp).
- Тёмной темы нет ни на одном экране → добавлены токены в `App UI Kit.dc.html`.
