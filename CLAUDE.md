# 8mart — правила для Claude Code (Flutter)

Прочитай перед любой задачей: README.md (структура, API-контракт, настройка платформ), docs/APP_AUDIT.md (чем приложение отличается от сайта), docs/OPEN_QUESTIONS.md, docs/APP_SPEC.md (push, настройки, документы, разрешения, аналитика).
Дизайн-референс — папка design/ (открыть через локальный сервер, см. design/README.md). Главный файл — design/App UI Kit.dc.html.

## Стек
Flutter 3.22+, Dart 3.4+. Bloc/Cubit (+ hydrated_bloc для корзины/избранного/настроек), go_router, Widgetbook. iOS + Android, один дизайн.

## Жёсткие правила
- Цвета — только `context.mc` (MartColors, light/dark). Размеры — MartHeight/MartRadius/MartSpace. Шрифт — MartText. Новых литералов цветов и размеров в экранах не писать.
- Экраны собирать только из `lib/ui`. Нужен новый элемент → сначала виджет в `lib/ui` + use case в Widgetbook, потом экран.
- Зона касания ≥ 44. Фото товаров — всегда через MartImage (белая подложка и в тёмной теме).
- Крестики/стрелки/± — геометрией (MartCross, MartChevron, MartPlusMinus), не символами шрифта.
- Деньги — `money()` («4 090 тг.»), в тексте — `moneyText()` («4 090 тг»).
- Все строки — в lib/l10n/app_ru.arb и app_kk.arb одновременно. Склонения — ICU plural.
- Основной CTA — MartButton(amount:). Kaspi — только KaspiPayButton (официальный SVG, без суммы, не перекрашивать).
- CTA заблокирован → disabledReason + текст причины в MartBottomBar(note:).
- Тарифы, пороги, тексты ошибок — в одном месте (ShippingConfig, ARB). Не дублировать.
- Секреты (DaData, Mapbox sk.*, ключи платёжного шлюза) в репозиторий не коммитить. Mapbox pk.* — через --dart-define.

## Бизнес-правила (сверено с макетами)
- Способ получения выбирается до первого добавления в корзину; иначе — шторка выбора.
- Распроданный товар остаётся в корзине, не считается, CTA заблокирован до удаления.
- Тяжёлые товары (delivery == cargo) — Газель завтра, тариф по весу; остальное — курьер сегодня. Смешанная корзина → выбор «Двумя доставками» / «Всё вместе завтра» (planShipments в lib/domain/shipments.dart). Бесплатная доставка от порога — только курьер. Подъём на этаж — liftFee × шт × (этаж−1).
- Самовывоз тяжёлого — только со склада, завтра.
- Статус — своя шкала на каждое отправление. Отмена — всего заказа, пока ни одно отправление не в доставке.
- Оплата: Kaspi или карта; у вошедшего — сохранённые карты (токены шлюза, только маска) + «Новой картой». Наличных нет.
- Вход: 4-значный код в WhatsApp; альтернатива — Telegram-бот (deep link t.me/<bot>?start=<token>, возврат /auth/tg). Face ID — предложить после первого входа.
- Push — спрашивать после первого заказа, не при запуске. Каталог и маршруты — lib/core/push.dart; promo и «забытая корзина» — только opt-in.
- Настройки (язык, тема, уведомления, Face ID) и Документы — Профиль → Настройки. Язык и тема применяются сразу.
- Бонусы: 1 бонус = 1 тг, product.bonus за шт, начисляются после получения, списать до maxPart%.

## Порядок работы
1. `flutter create . --org kz.mart8 --platforms ios,android` (lib/ не перезапишется), `flutter pub get`, `flutter gen-l10n`.
2. `flutter analyze` и `flutter test` — починить всё, что найдёт (код писался без компилятора).
3. Заменить MockData на репозитории по API-контракту из README; формы моделей не менять без согласования.
4. Доделать экраны из «TODO» в README, сверяясь с design/.
5. После каждого шага — analyze + test + прогон в Widgetbook в обеих темах и на казахском.
